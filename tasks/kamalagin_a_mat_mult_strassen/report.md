## 1. Введение
В этой работе реализованы последовательная и параллельная версии алгоритма умножения плотных матриц с элементами типа doubleс использованием алгоритма Штрассена и технологии MPI.
А также проведена проверка корректности с помощью функциональных тестов + оценка производительности с помощью cоответствующих тестов

## 2. Постановка задачи
Даны две квадратные матрицы A и B размера N × N, элементы которых имеют тип double. Требуется вычислить результирующую матрицу C размера N × N,
определяемую следующим образом:
C = A · B
Вход:
- Матрица A размера N × N 
- Матрица B размера N × N
Выход:
- Матрица C размера N × N — результат умножения матриц
Ограничения:
- Размер матриц может быть произвольным и достаточно большим.
- Алгоритм должен корректно обрабатывать граничные случаи, включая пустые матрицы и матрицы малого размера.

## 3. Базовый алгоритм
Последовательный алгоритм умножения матриц реализован с использованием алгоритма Штрассена в итеративной форме.

Алгоритм Штрассена основан на рекурсивном разбиении исходных матриц A и B размера N × N на четыре подматрицы размера (N/2) × (N/2).
В отличие от классического алгоритма умножения матриц, который требует восемь умножений подматриц, алгоритм Штрассена использует только семь умножений,
что позволяет уменьшить асимптотическую сложность вычислений.

В данной реализации рекурсивный подход заменён итеративным: вместо рекурсивных вызовов используется явный стек вычислений, в котором хранятся промежуточные состояния алгоритма.
Это позволяет избежать глубокой рекурсии и упростить контроль за использованием памяти.

На каждом шаге вычисляются семь промежуточных матриц, на основе которых формируются подматрицы результирующей матрицы.
При достижении минимального размера подматриц используется стандартный алгоритм умножения матриц.

## 4. Схема распараллеливания
Процесс с рангом 0 выполняет роль корневого процесса и отвечает за разбиение исходных матриц на подматрицы, распределение вычислений между процессами
и сбор итогового результата.

Параллелизация алгоритма осуществляется на верхнем уровне декомпозиции алгоритма Штрассена. Вычисление отдельных промежуточных произведений,
используемых в алгоритме, распределяется между MPI-процессами.

Каждый процесс независимо вычисляет назначенную ему часть данных с использованием итеративной реализации алгоритма Штрассена, после чего результаты передаются корневому процессу
для формирования результирующей матрицы.

## 5. Детали реализации
Реализация задачи разделена на последовательную и параллельную версии, расположенные в соответствующих поддиректориях проекта.

Последовательная версия реализует алгоритм Штрассена в одном процессе без использования средств параллелизации и без рекурсивных вызовов.
Вычисления выполняются итеративно с использованием собственного стека состояний алгоритма.

Параллельная версия реализована с использованием библиотеки MPI. Основная логика вычислений сосредоточена в методе Run,
а подготовка и проверка входных данных выполняются на этапе предварительной обработки.

В реализации предусмотрена корректная обработка граничных случаев, включая ситуации с малыми размерами матриц.
Дополнительная динамическая память используется для хранения промежуточных подматриц и результатов вычислений.
